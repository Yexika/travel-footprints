    备份与恢复

    把全部标记复制成一段文字存起来；需要时粘贴回来导入，会和现有标记合并。

    把足迹保存到 GitHub 仓库

    连接后，每次标记都会自动写进仓库里的 footprints.json，换设备打开也同步，别人打开网址能看到你的足迹（只读）。

    怎么拿到令牌？
    1. 打开 GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
    2. Repository access 选 Only select repositories，只勾这个地图仓库。
    3. Permissions → Repository permissions → Contents 选 Read and write，其他不用动。
    4. 生成后复制以 github_pat_ 开头的令牌，粘贴到上面。

    令牌只保存在这台设备的浏览器里，不会上传到别处。公用电脑上不要连接。

    登录后一起编辑

    账号由地图主人添加。登录后可以和主人一样标记、修改、删除，改动会保存到同一张地图上，两个网址都能看到。
